## Τρέχουσα αντιστοίχιση κατηγοριών
- Ποντίκι: a, b
- Πληκτρολόγιο: a, b, g
- Υπολογιστής: a, b, g, d
- Υπολογιστική Σκέψη: b, g, d, e, st
- Σχεδίασε: a, b, g, d, e, st
- Γνώση & Τακτική: a, b, g, d, e, st
- Διαδίκτυο: d, e, st
- Ρομποτική: g, d, e, st

Οι κωδικοί τάξεων είναι:
a=Α΄, b=Β΄, g=Γ΄, d=Δ΄, e=Ε΄, st=ΣΤ΄
